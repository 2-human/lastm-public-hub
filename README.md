# lastm-public-hub

Public surface mirrored from `public/hub/` in `2-human/lastm-private` by `.github/workflows/sync-public.yml`.

This surface serves an **encrypted password gate only** (AES-256-GCM + PBKDF2-HMAC-SHA256, 600k iterations, decrypted in the browser via Web Crypto). The plaintext lives only in the private repo and is never published.

| File | Purpose |
|---|---|
| `index.html` | The encrypted gate (generated by `encrypt.py`; never edit by hand). |
| `encrypt.py` | Encrypts `../../content/hub/index.html` into `index.html`. |
| `.nojekyll` | Serve files as-is. |

## Update the content

Edit the canonical brief in the private repo, re-render, push:

```
python3 work-setup/render-hub.py
git add content/ && git commit -m "hub: update" && git push
```

CI sees that `content/hub/index.html` changed and re-encrypts with the `HUB_GATE_PASSWORD` secret before mirroring. To encrypt locally instead: `python3 public/hub/encrypt.py "$PASSWORD"` (needs `pip install cryptography`).

## Rotate the password

1. `gh secret set HUB_GATE_PASSWORD -R 2-human/lastm-private`
2. `gh workflow run sync-public.yml -R 2-human/lastm-private` (manual dispatch always re-encrypts)
3. Share the new password out of band.
